# Validation for 1.0.0

The user accepted the final visual direction and requested the final release.
The six active styles are Alliance, Horde, Satin, Clear Black, Orbit Black and Free; Satin is the default.

The fundamental marker workflow was previously confirmed in the actual game, including combat.
Independent local checks cover the expanded settings, protected action dispatch, marker subsets,
responsive layout, mouse-responsive preview, category/tab restoration, migration and texture diagnostics.
Asset compositions were inspected separately. Simulations and asset compositions are not gameplay screenshots.

This record does not claim a fresh exhaustive live test of every appearance, group role, hardware binding
and combat state in the final build. WoW still controls marking permissions, range and valid ground.

Die Gestaltung wurde vom Nutzer angenommen. Der Grundablauf wurde zuvor im Spiel einschließlich Kampf
bestätigt; die Erweiterungen wurden lokal unabhängig geprüft. Eine vollständige neue Live-Matrix jeder
Stil-, Gruppen-, Hardware- und Kampfkombination wird damit nicht behauptet.
