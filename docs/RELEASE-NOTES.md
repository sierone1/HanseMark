# Hanse Mark 1.0.0

Initial release for WoW Forever with six selected appearances, native German/English settings,
selectable world markers, safe visual previews, key assignment and click/hold interaction.

Install the HanseMark folder and fully restart WoW. Open /hansemark and assign a key.
Satin is the default appearance. Existing settings migrate to the six-style catalog.

Erste Veröffentlichung für WoW Forever mit sechs Gestaltungen, deutschen und englischen Einstellungen,
frei wählbaren Bodenmarkierungen, Vorschauen und bewusster Tastenverwaltung.
Den Ordner HanseMark installieren, WoW vollständig neu starten und unter /hansemark eine Taste zuweisen.
