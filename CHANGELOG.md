# Changelog

1.0.0 — initial release
- Six selected appearances: Alliance, Horde, Satin, Clear Black, Orbit Black and Free.
- Satin default; existing preferences migrate to the six-style catalog.
- Native German/English settings with Interaction, Markers, Appearance and Info tabs.
- Responsive controls, clean scrolling and embedded preview.
- Large mouse-responsive visual preview restores the same category and tab on closing.
- Configurable marker subset, ring/icon size, opacity, labels, neutral zone and edge handling.
- Explicit key assignment/conflict confirmation and settings reset preserving bindings.
- Checked texture loading and visible preview diagnostics.
- Manual protected world-marker workflow; no automatic boss logic.
